# 净屏 · CleanYourTV 中文版 宣传片

## 成片

`净屏-CleanYourTV-中文版.mp4` — 1920×1080 / 24fps / **88.0s** / h264 + aac / 12 MB
配音：亖米19（voice19_2026, speed 1.05），**整条一次性合成**

## 名字

英文 `CleanYourTV` 直译不成句，中文名取 **「净屏」** —— 两个字，说清它干的事：
把电视上那些广告位、推荐位、会员入口清掉，只留一块干净的屏。

## 文案结构（参考热门产品视频写法）

不是念参数，用的是 2026 年通行的五段结构：

| 段 | 时间 | 作用 | 我们写的 |
|---|---|---|---|
| 钩子 | 0–3.7s | 前 3 秒决定 60% 的人划不划走 | 「这三十秒，你每次真的看完了吗？」（痛点前置） |
| 对比 | 3.7–6.0s | 让痛感落地 | 左：红 ✗ 四项负担 ↔ 右：真实桌面 |
| 是什么 | 6.0–16.2s | 一句话说清 | 「把电视桌面换成你自己的」+ 442 机型 / 72 品牌 / 576 KB |
| 怎么解决 | 16.2–50.2s | **占一半篇幅，演示不是说明** | Android 6 能装 → 动态壁纸原速录屏 → 半透明卡片（0.22/0.36 时间线）→ 频率排序 |
| 凭什么信 | 50.2–82.3s | 可验证证据 | 576 KB / 24 MB / 13 ms / 1.6% + 133ms 空洞的帧时间示意图 |
| 下一步 | 82.3–88.2s | 只给一个动作 | 仓库地址 + 四个标签，降速收口 |

三条纪律：**写不出版面的功能不上视频**（11 项差异只留 4 项）、一镜一卖点、能量化的不说形容词。

## 声音必须整条合成（这是硬约束）

第一版按 7 段分开合成，实测语速 **4.76 ~ 6.73 字/秒，差 1.41 倍** ——
听感就是「一会快一会慢」。MiniMax 的 t2a 不保证跨请求一致。

现在：`speak.txt` 整条一次合成 → `speak.mp3`（86.56s，语速 5.86 字/秒唯一）
→ whisper 转写拿每句时间戳 → `align.py` 把 10 幕的起点写回 `index.html`。

**画面跟着语音走，不是语音塞进画面。**


## 字幕（`subs.py`）

42 行，跟着配音走。

- **时间**用 whisper 的 `speak.json`（真实语音时间）
- **文本**用 `speak.txt` 原文 —— whisper 会把「净屏」听成「静平」、「臃肿」听成「雍总」，
  字幕直接用它就露馅
- 切分**句号优先**：一句话一行，只有超长才按逗号拆。
  按逗号切会切出「关不掉，/ 也删不掉。」两段，合并时又跟上一句粘住，
  出现「你每次真的看完了吗？关不掉，」这种跨句字幕（实测）
- 样式：底部 76px 居中、半透明底 + 模糊、30px、单行

## 背景不是纯黑

纯 `#000` 大平面在电视上会「发干」。现在底是
`radial-gradient` 冷调渐变 + 80px 细网格 + 3.5% 噪点，左侧一条绿色渐隐竖线做结构。

## 怎么改

```bash
# ① 改文案（speak.txt，一段一行）
vi speak.txt

# ② 整条重配音（不能分段，会漂）
python3 -c "import runpy; runpy.run_path('/tmp/one-shot.py')"   # 或重跑一次性合成脚本

# ③ 转写拿时间戳（约 5 分钟）
whisper speak.mp3 --model small --language zh --output_format json --output_dir . --fp16 False

# ④ 对齐：写 timeline.json 并把时间轴注入 index.html
./align.py

# ⑤ 生成字幕并注入（42 行，句号优先切分）
./subs.py

# ⑥ 渲画面（2116 帧约 105 秒）
./render.py

# ⑦ 混音（整条铺上去，apad 补到 88.16s）
./mix.py
```

页面必须暴露 `window.__frame(t)` 且返回 Promise —— s5 要等 `video.seeked` 才截图，
否则会拿到上一帧。
