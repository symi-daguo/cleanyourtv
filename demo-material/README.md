# CleanYourTV 中文版 · 演示素材说明

给做视频的人：这个文件夹里是**已经录好/截好**的素材，外加一份「拍什么、怎么讲」的说明。
素材本身不进代码仓库（仓库根目录的 `.gitignore` 已排除 `demo-material/`），只在这里交付。

---

## 一、这是什么

**CleanYourTV** 是给 Android TV / 国产电视做的第三方桌面：把电视自带的臃肿桌面换成一个干净的、
只显示应用本身的启动器。上游作者是 [Gathin23](https://github.com/Gathin23/cleanyourtv)，社区 200+ 人参与。

**这个仓库是中文本地化分支**（`symi-daguo/cleanyourtv`），基于上游 **v3.4.0**（442 款电视型号、72 个品牌）。

---

## 二、相对官方原版，这个分支多做了什么

| 能力 | 说明 | 为什么重要 |
|---|---|---|
| **能装到 Android 6.0 的老电视** | 官方最低 Android 8.0；这里用 `-PlauncherMinSdk=23` + desugar 的 `java.time` 编译出 23 版 | 海信 VIDAA、小米老款、创维等大量在用电视还停在 Android 6 |
| **这类机器自带 5 张背景图** | 官方版在 Android 6 上**装完一片空白**（外部存储被裁掉，图片推不进去）；这里把 5 张图编译进 APK，按分钟轮换 | 唯一能在这类电视上看到背景的办法 |
| **照片当桌面，会动** | `wallpaper_motion`：照片做 20 秒一轮的缓慢平移+呼吸式推拉，方向每次随机 | 官方是静态图；这一下从"壁纸"变成"动态画布" |
| **换图有淡入淡出** | 0.22 秒淡出 → 换图 → 0.36 秒淡入，且**从不淡到全黑**（淡到全黑会出现一帧纯黑，看着就是硬切） | 官方是硬切 |
| **卡片半透明** | `tile_opacity`：卡片背景能调成半透明，照片从卡片下面透出来 | 官方卡片是实心深灰，照片被一格一格盖住 |
| **第一行没有那条宽底板** | `dock_band` 默认改关；焦点移到下面几行时，第一行不会留一条看着像"卡住"的固定条 | 官方默认开着，很多人第一反应就是"焦点卡住了" |
| **照片上不糊光晕** | 有照片时自动关掉聚焦应用的环境光 | 官方光晕会把整张照片染成图标的主色（绿图标 → 整张照片泛绿） |
| **应用按使用频率排序** | 读系统使用统计，用得多的排前面；没授权时退回字母序 | 省掉每次自己拖 |
| **进别的 app 会暂停，回来接着走** | 轮播和动态在后台冻结，回来从暂停处继续，不重置计时 | 官方回来会立刻换图 |
| **开机自启** | `power_on_home`：开机后自动抢回桌面 | 很多电视开机自己跳 Live TV |
| **完整中文** | 界面、文档、技能包全中文；`locale` 键可只给这个桌面设中文 | — |

## 三、建议拍的镜头

按 `record-demo.sh` 的顺序，素材已经齐了：

| 素材 | 内容 | 视频里怎么用 |
|---|---|---|
| `01-home.png` | 桌面全景 | 开场定格，讲"这是什么" |
| `02-focus.png` | 焦点移到应用行 | 讲焦点反馈、卡片半透明 |
| `03-wallpaper-motion.mp4` | **30 秒录屏，含缓慢平移与换图** | **核心镜头**，讲动态背景 |
| `04-apps.png` | 应用列表 | 讲按使用频率排序 |
| `perf.txt` | 帧时间、内存、崩溃数 | 结尾数据页 |

### 核心镜头（03）值得慢放

动态背景是"缓慢平移 + 轻微推拉"，**20 秒一个来回**，方向每轮随机。
建议：原速播 10 秒 → 慢放 0.5× → 加速到换图瞬间（淡出淡入）→ 原速。

## 四、可以放上屏幕的数据

在海信 VIDAA（maxim 芯片，Android 6.0，1280×800）实测：

| 指标 | 数值 |
|---|---|
| 屏幕刷新率 | 60 Hz |
| 壁纸动画 95% 帧时间 | 13 ms（60fps 的预算是 16.7 ms） |
| 掉帧率 | 1.6% |
| 内存占用 | 24 MB |
| 崩溃 | 0 |
| APK 体积 | min26 **576 KB** / min23 **1278 KB** |

**576 KB 是这个项目最值得讲的一点**：整台电视的启动器只有半兆多，官方也把 576 KB 定为硬门槛，
因为目标是 1 GB 内存的老电视。

**一个要如实说的限制**：这台 maxim 芯片的帧时间线上，每约 11 帧就有一次 133 ms 的空洞。
实测把我们的动画整个关掉，这个空洞照样在 —— 来自芯片和海信系统本身。
所以动态背景能做到的是「慢到你察觉不到那 133 ms」，而不是「绝对不掉帧」。
视频里不必回避这一点，讲清楚反而更可信。

## 五、连不上电视怎么办

海信这类机器的 adbd 有一个老毛病：**TCP 5555 端口开着，但 adb 握手会被拒**（显示 `offline`）。

**解法（必须在电视上操作）**：

1. 设置 → 关于 → 连点「版本号」7 次，进开发者选项
2. 关掉「网络调试 / ADB 调试」，等 3 秒
3. 再打开，电视上弹「允许 USB 调试吗」，点**允许**（勾「一律允许」）
4. 或者直接**拔电源插头 30 秒再插上**

恢复后：

```bash
./record-demo.sh 192.168.2.67
```

脚本会自动：装最新包 → 授权使用统计 → 截 4 张图 → 录 30 秒屏 → 打印帧率和内存。

## 六、口播要点（可直接用）

> 这是一个给国产电视做的第三方桌面。官方版本只支持 Android 8.0 以上，
> 而国内还有大量海信、小米、创维的老电视停在 Android 6，官方装上去是一片空白。
>
> 这个中文分支补上了这条路：能在 Android 6 上跑，还自带五张背景图，
> 因为那类机器的外部存储被裁掉了，照片根本推不进去。
>
> 功能上比官方多了几样：照片能当动态桌面，会缓慢平移，每一圈走的是不同的随机路线；
> 换图是淡入淡出而不是硬切；卡片能调成半透明，照片从下面透出来；
> 应用还能按你实际的使用频率自动排序。
>
> 整套东西 576 KB —— 因为目标是 1 GB 内存的老电视，每一 KB 都要算。
>
> 顺便说个实在的：这台电视的芯片在渲染上有个自己的毛病，每十几帧会停一下。
> 这不是我们做的，官方版停得一样。我们能做的是让背景慢到你察觉不到那一下，
> 而不是硬说它不卡。
